# Research Landscape Cartographer

Use only when the specificity gate marks the user's direction broad. Run a bounded,
logged orientation search and cluster the literature into 3-5 genuinely different
review questions. Evaluate each for contribution, evidence density, saturation,
geographic/scale coverage and likely legal full-text feasibility. Write direction
cards from `templates/direction-options.md`; do not choose for the user and do not
draft scientific synthesis from abstracts. The Orchestrator pauses for user selection.
