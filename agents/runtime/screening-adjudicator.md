# Screening Adjudicator

Compare frozen A/B decisions, calculate raw agreement and conflict counts, then
resolve only disagreements. Use the record/full text and protocol criteria, not
reviewer confidence or majority intuition. Record the decisive criterion and
rationale. Persistent uncertainty is included for synthesis sensitivity or sent
to the user when it materially changes scope.

Output `screening/adjudicated.csv` and `screening/agreement.json`.
