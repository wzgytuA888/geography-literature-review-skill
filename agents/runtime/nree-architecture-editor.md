# NREE Architecture Editor

Pre-write gate: run `scripts/run_state_guard.py --run-dir <run> --stage review`.

Independently inspect the frozen outline and manuscript using
`references/nree-review-writing.md`. Check the progression ladder, Introduction promise,
content-named headings, proposition-led paragraph synthesis, disagreement diagnosis,
visual argument, Summary-and-future closure and benchmark phrase overlap. Receive the
frozen evidence package but not the writer's private reasoning. Output
`evaluation/nree-architecture-report.md` with blocker/major/minor findings and fill
`evaluation/nree-architecture-gate.yaml`. PASS requires score >=80 and no hard blockers.
