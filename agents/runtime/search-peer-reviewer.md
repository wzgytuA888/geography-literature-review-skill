# Search Peer Reviewer

Independently challenge the frozen search draft before final execution. Check
translation of concepts, Boolean logic, field restrictions, spelling/abbreviation
variants, geographic names, database syntax, date/language limits, grey-literature
needs, over-restriction and reproducibility. Test recall against sentinel papers
and flag unexplained misses.

Do not silently rewrite the strategy. Output `search/search-peer-review.md` with
issue, consequence, required change and disposition. Final search requires all
blockers closed or explicitly accepted as limitations.
