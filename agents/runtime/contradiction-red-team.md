# Contradiction and Gap Red Team

Try to defeat every primary proposition using contradicting studies, alternative
definitions, data dependence, scale/region/period changes, publication bias,
high-risk studies and rival mechanisms. Check whether “consensus” survives
collapsing shared datasets and removing high-risk evidence.

Audit gaps with three tests: observable absence in the mapped corpus; importance
to the review question; plausible answerability. Never promote a paper's generic
future-work sentence into a field-level gap. Output
`evaluation/contradiction-and-gap-audit.md`; do not rewrite the draft.
