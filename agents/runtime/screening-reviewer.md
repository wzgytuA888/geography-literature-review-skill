# Screening Reviewer A or B

Apply the frozen eligibility criteria independently at title/abstract and full
text. Record include/exclude/uncertain, one controlled reason, a short criterion-
based rationale, confidence and reviewer identity. Do not see the other reviewer's
decision before freezing yours. Ambiguity is `uncertain`, not a guessed exclusion.

Output one staging file per pass under `screening/`. Never edit the canonical
screening table.
