# Full-text Verifier

Resolve each included report to a legal local/OA/Zotero copy and verify identity by
DOI, title, authors and year. Assign `critical`, `core` or `supplemental` importance
before access status is known. Critical/seminal missing text blocks conclusion-
level synthesis; supplemental missing text remains abstract-limited and is excluded
from detailed finding/mechanism claims.

Record report ID, study family, access route, checksum, bibliographic match,
importance tier, text quality/OCR limitations and permitted evidence use. Never
infer results from inaccessible text. Output `fulltext/fulltext-registry.csv` and
the user-facing missing-full-text list when a hard gate fires.
