# Section Patterns — introduction moves, body logic, transitions, previews

consolidated: 2026-08-26, N=60
Tiers: corpus-consensus >=30/60; common >=12/60; variant <12 multi-doc; outlier single-doc.

## Introduction move sequence [corpus-consensus, ~42/60]
Canonical five-move opening, in order:
1. Global-change/system stakes framing (why the class of phenomenon matters).
2. Quantified stakes: at least one hard number with units (impacts, demand multiples, event costs)
   in the first paragraphs. (B001,B004,B005,B007,B011,B013,B016,B019,B021-B026,B031-B040 first-
   paragraph rule 10/10,B041-B050 10/10,B051-B060 8/10)
3. Need/gap statement justifying a new synthesis.
4. Objective sentence in first-person-plural ("In this Review, we ...").
5. Sequential roadmap with ordered discourse markers ("We begin ... We then ... Finally ...").
(B002,B003,B007,B010,B011,B012,B013,B015,B016,B017,B018,B020,B021,B022,B024,B025,B027,B028,B029,
B031,B032,B034-B037,B041,B042,B044-B048,B050,B051,B054,B056,B058,B059,B060)

### Gap-framing sub-types [family common, ~28/60 pooled]
- Fragmentation/silo statement: fields studied independently despite links. (B005,B010,B022,B023,B029,B030,B051,B052)
- Corrected flawed assumption/metric rather than missing study. (B016,B017,B018,B019)
- Update-gap since named prior synthesis ("N years since last comprehensive review"). (B011,B012,B015,B021)
- Narrowness-of-prior-work / absence-of-integrated-synthesis. (B041,B042,B045-B048,B050,B051,B052)
- Controversy staged up front as the tension to adjudicate. (B029,B030) [variant]
- Positioning against prior reviews, redirecting readers for method depth. (B011,B012,B015)

### Scope discipline [common, ~22/60 pooled]
- Inclusion list PLUS justified exclusions with reasons stated early. (B002,B009,B011,B012,B022,
  B024,B025,B028,B041,B044,B048,B049,B054,B055,B059)
- Numeric inclusion/exclusion criteria or era windows embedded in scope statements.
  (B041 fringe/area thresholds; B048 database bounds; B053,B058 numeric windows) [variant]
- Key constructs defined operationally at first use; glossary/Box variants exist. (B003,B004,B005,
  B007,B010,B011,B017,B020,B043,B045,B046,B047,B052,B055,B057)

## Body-section internal logic
- Definition-first openers: a section opens by defining its concept before any evidence.
  (B011,B017,B018; also primer pattern in review-architecture.md) [common]
- Parallel mirrored subsection threads: same move order repeats per thread so cross-category
  comparison is effortless. (B001,B002,B003,B005,B006,B017,B018,B022,B025,B028,B030,B033,B040,
  B042,B046,B047,B050) [common]
- Region/class blocks run a repeated micro-template (prevalence -> drivers -> case anchor ->
  need note). (B033,B040) [variant]

## Transition devices [all observed families]
- Preview/preamble sentence announcing what the section will do before content starts.
  (B004,B023,B024,B026,B027,B031,B035,B037,B044,B046,B047,B051,B053,B055,B056,B058,B060; ~17/60)
  [common]
- Pivot sentences at boundaries handing off between layers (understanding->decision, physical->
  social, diagnosis->management), placed at section edges not mid-section. (B001,B021,B023,B024,B026) [common]
- Recap-and-link transitions ("Before discussing X, we highlight Y"). (B011,B015) [variant]
- Extension/escalation moves between adjacent sections. (B001 card) [variant]
- Sibling-section hand-off motivating the next unit. (B018,B040,B045,B042 positional hand-off) [variant]
- Content-logical arc transitions: consequence follows pressure; critique follows drivers.
  (B042,B044,B045,B048) [common]

## Roadmap fidelity [rubric-grade signal]
Introduction-promised section order equals delivered order; verbs map 1:1 onto headings.
(B005,B006,B007,B009 TOC,B010,B015,B017,B020,B031-B037 verbatim,B041,B042,B044-B048,B050,
B051,B054,B056,B058-B060; verifiable in most, testable in all) [corpus-consensus]
Variant: abstract-carried mini-TOC instead of prose roadmap. (B003,B009) [outlier-to-variant]
