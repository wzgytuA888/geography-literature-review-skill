# Geography Reasoning Patterns — CONDITIONAL rules with observed frequencies

consolidated: 2026-08-26, N=60
Tiers: corpus-consensus >=30/60; common >=12/60; variant <12 multi-doc; outlier single-doc.
Each rule is CONDITIONAL: IF <trigger> THEN <move>. Geography is never decorative in this corpus;
every regional statement arrives with its evidence condition.

## R1. Region-divergence -> regional differentiation WITH the why [corpus-consensus, ~38/60]
IF a trend, sensitivity or response differs between places,
THEN invoke regional differentiation AND name the mechanism/evidence condition that sets the
difference (signal-to-noise ratios, moisture-source geography, tectonic margin type, biome fuel
limits, clay mineralogy, land-atmosphere coupling strength, sediment/sea-level driver mix,
climate-mode footprint).
Evidence: B001,B002,B003,B004,B006,B007,B010,B011,B014,B016,B017,B019,B020,B021,B024,B026,B027,
B028,B029,B030,B031,B032,B033,B036,B038,B046,B047,B048,B050,B052,B053,B054,B055,B056.
Form rule: no regional claim without its why; decorative regionalism is absent corpus-wide.

## R2. Scale-shift -> scale dependence stated explicitly [corpus-consensus, ~30/60]
IF the analysis shifts scale (segment->network, plot->plateau, gridpoint->globe, event->climate),
THEN state what changes with scale (aggregation-time effects, footprint mismatch, cumulative
impacts) and organize via explicit scale ladders or space-time matrices.
(B003,B004,B007,B011,B015,B018,B019,B021,B023,B031,B036,B037,B038,B040,B042,B045,B047,B048,B049,
B051,B053,B058,B060)

## R3. Flows between places -> flow/network reasoning [common, ~14/60]
IF effects propagate along physical or economic pathways,
THEN connect places into systems: teleconnections, upstream->downstream pulses, hillslope-channel
coupling, land->ocean transfer, trade/telecoupling arrows, source-sink reciprocity.
(B007,B009,B013,B019,B020,B031,B034,B037,B045,B052,B053,B054,B055,B059,B060)

## R4. Continuous spatial variation -> zonal-gradient stratification [common, ~15/60]
IF the mechanism varies continuously with climate or position,
THEN disaggregate claims by aridity class, precipitation zone, elevation band, latitude, reach
position (source/middle/lower), or upstream/downstream status; distance-decay gradients serve as
causal evidence, and spatial position may organize whole papers.
(B021,B023,B024,B026,B027,B029,B030,B041,B042,B049,B050,B056,B053,B058)
Position-as-architecture subset (whole papers organized by spatial position): B042,B049,B050,
B058 single-place variant [variant].

## R5. Uneven coverage -> archive/data-density as gap evidence [common, ~14/60]
IF knowledge is unevenly distributed,
THEN map/quantify archive and observation density and read absence-of-records as absence-of-DATA,
never absence-of-phenomenon; geographic imbalance of the evidence base itself becomes gap
evidence (study-distribution maps, coverage-vs-extent comparisons, record-start dates bounding
trends, network sparsity).
(B011,B015,B016,B019,B020,B023,B025,B028,B032,B037,B038,B040,B055,B057)

## R6. Upscaling -> cross-scale caution [common-borderline, ~10/60 documented]
IF site/plot/local evidence is generalized to region or globe,
THEN attach explicit upscaling limits and methods (common reference frames, comparability
conditions, moving-window designs, stated representativeness limits); decision-relevance framing
names the scale at which answers are needed.
(B011,B020,B024,B026,B027,B029,B030,B051)

## R7. Place names as evidence anchors, not narrative detours [corpus-consensus, ~32/60]
Named events/cities/rivers/deltas instantiate generic claims with magnitude + period + citation;
places calibrate but never organize sections — except single-place deep syntheses where one
region's internal geography IS the analysis (B023,B058; outlier class 2/60).
(B001-B004,B010,B011,B013-B018,B020,B031,B036,B037,B040,B041,B046-B049,B051,B053,B056,B060)

## R8. Human footprint as first-class structural variable [common-high, ~28/60]
IF human systems interact with the reviewed process,
THEN treat engineering works, water law, markets, programmes and policies as causal components
inside the synthesis (cited, tabulated, assessed), co-equal with climate drivers; exposure/
vulnerability enters as a system variable, not backdrop.
(B003,B004,B005,B007,B009,B022,B023,B024,B025,B026,B029,B030,B032,B034,B037,B038,B040,B042,B044,
B045,B046,B048,B049)
Purely physical reviews instead bound human stakes to intro and close. (B001,B041,B047,B050,B058)

## R9. Heterogeneity-as-message -> quantified spatial heterogeneity [variant, ~6/60]
IF spatial heterogeneity is itself the finding,
THEN quantify it falsifiably (percent-of-area statements, per-segment mosaics, continent-ranked
rates). (B001,B006,B023,B046,B049,B056)

## Cross-cutting caution
Uniform prescriptions across regions with divergent drivers break the R1 contract; the corpus
explicitly performs the opposite move (region-specific intervention logic). (B054 counter-example note)
