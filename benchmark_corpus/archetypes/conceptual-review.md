# Archetype: Conceptual Review

consolidated: 2026-08-26, N=60
Corpus coverage: MODERATE — 5/60 card-labelled conceptual docs (B005 cycle-framework lens,
B010 metric-taxonomy concept review, B043 framework-genealogy uptake review, plus conceptual-
flagged variants B003 dynamical-systems lens and one internal-vs-external-dynamics doc). All are
concept reviews embedded in the same house skeleton; free-standing theory essays are absent.

## Signature architecture
- Same house skeleton as other archetypes, but body sections mirror CONCEPT components rather than
  phenomenon classes: framework parts, metric families, or definition lineages.
- Lens-first: an early section/Box establishes the conceptual toolkit (vocabulary, thresholds,
  baseline model) that later sections must obey. (B003 tipping vocabulary; B005 natural-cycle
  baseline; B010 five-metric taxonomy)
- Higher tolerance for zero-citation prose: conceptual paragraphs legitimately run uncited
  (zero-cite shares up to ~29-44% in concept-heavy docs). (B032,B035,B037,B040,B057,B060 pattern)

## Signature rhetoric
- Terminology census as an opening move: existing synonym families catalogued exhaustively with
  citations, then either adjudicated by operational definition or resolved by introducing ONE
  unifying formalisation. (B010 metric pluralism confronted; B047 twelve-plus synonyms -> new
  metric; B057 consensus-definition anchoring then author-operationalized redefinition)
- Contribution = conceptual artefact (unifying definition, metric, typology, genealogy), not only
  summary; contribution stated as arguable thesis. (B031,B032,B034,B039 thesis-register docs overlap)
- Disputes recast as convention/threshold choices rather than factual conflicts. (B001,B010)

## Evidence apparatus
- Definition/glossary Boxes carrying formulas and term tables; comparison tables across definitions
  or framework versions. (B010,B043,B045 glossary variants)
- Uptake/genealogy timelines documenting framework evolution. (B043) [variant]
- Lower figure pressure acceptable when the unit of analysis is a concept; density may sit at
  median ~2 cites/block. (B057,B060 stats)

## Exemplar doc IDs
B003, B005, B010, B043, B057.

## Imitation risks (from cards)
Insider-framework reviews need external uptake evidence (B043 risk); metric proposals without
formal work mislead (B047 risk); definitional quarantining fails if analytic sections re-litigate
terms (A4/A15 anti-patterns).
