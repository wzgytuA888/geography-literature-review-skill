# Archetype: Systematic Review

consolidated: 2026-08-26, N=60
Corpus coverage: THIN — 2/60 card-labelled systematic docs (B023 framework-driven synthesis of an
enumerated 427-study evidence base; one further doc labelled systematic). Semi-systematic hybrids
are the real corpus mode: reviews that audit and recompute from an evidence base without full
protocol machinery (B017 own compilation; B025 interval bounds; B029 meta-effect sizes; B037/B038
sample-size-reported pooling).

## Signature architecture (as represented in corpus)
- Named analytical framework adopted in the Introduction; body headings mirror its slots exactly
  (drivers -> pressures -> states -> impacts -> responses pattern). (B023)
- Evidence base enumerated, counted, mapped: study counts per category visualized as a distribution
  figure so coverage becomes an argument. (B023 Fig2 pattern; B048 database bounds variant)
- Dedicated gaps section/figure distilled FROM the audit. (B023 two-stage derivation)

## Signature rhetoric
- Framework-slot filling with explicit positioning of each evidence item into exactly one slot,
  then slot-to-slot connection sentences.
- Quantified pooling with per-row provenance; interval reporting over point estimates.
- Policy/plan documents integrated as analysable data (tabulated goals, cited by code).
- Gaps read off the mapped distribution — absence-of-studies is demonstrated statistically before
  being declared.

## Full-protocol elements NOT represented in this corpus
Registered protocols, exhaustive database search strings, PRISMA flow diagrams, formal dual-screener
quality appraisal, risk-of-bias scoring. Where corpus reviews approach these (compilation protocol
Boxes, search-term disclosure), they use Boxes/supplements rather than methods sections:
(B037 protocol Box; B036,B037 supplementary-methods pointers; B045 supplementary data files).

## Exemplar doc IDs
B023 (canonical in-corpus exemplar); B017,B025,B029,B037,B038 (semi-systematic quantitative
hybrids); B048 (inventory-bounded variant).

## Imitation risks (from cards)
Framework rigidity can force ill-fitting studies into slots (B023); recomputation forms mimicked
without genuine rigour mislead — pair every new number with n, dispersion, derivation pointer
(batch-3 discipline note).
